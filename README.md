# SEKTOR

Coach de pilotage local pour iRacing et Le Mans Ultimate, sous Windows.

Ce dépôt ne contient que les versions publiées de l'application : l'installateur Windows de chaque version et le
fichier `latest.json` que l'application lit pour se mettre à jour. Le code source n'y est pas publié.

## Installer

Télécharger `SEKTOR_<version>_x64-setup.exe` dans la [dernière version](../../releases/latest) et le lancer.
L'installateur n'a pas de certificat Windows : SmartScreen affiche un avertissement au premier lancement
(« Informations complémentaires », puis « Exécuter quand même »).

Une fois installée, l'application signale elle-même les nouvelles versions et les installe sur demande.
